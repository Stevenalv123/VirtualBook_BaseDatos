# 📚 Biblioteca Virtual

**Biblioteca Virtual** es una aplicación desarrollada en **C# (Windows Forms)** y una **Web API en ASP.NET Core** que permite gestionar libros, autores, editoriales, usuarios, roles, reseñas y más. Está diseñada para ofrecer una experiencia sencilla, moderna y funcional para usuarios que desean acceder a libros de manera digital.

## 🚀 Características principales

- 📖 Visualización de libros en formato de tarjetas (cards).
- 🔍 Búsqueda y filtrado de libros.
- 👤 Gestión de usuarios, roles y perfiles.
- 📝 Reseñas y valoraciones de libros.
- 🗃 Registro de historial de lectura y descargas.
- 🖼 Carga de imágenes para portadas de libros y fotos de perfil.
- 📡 API RESTful para conectar frontend con base de datos.

## 🛠 Tecnologías utilizadas

- **C#** - Windows Forms (Frontend)
- **ASP.NET Core Web API** - Backend
- **Entity Framework Core** - ORM y acceso a datos
- **SQL Server** - Base de datos
- **Mathos Parser** (en otros módulos)
- **Visual Studio 2022**
